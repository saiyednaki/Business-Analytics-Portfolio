# Welcome

Most portfolios introduce technologies.

This portfolio introduces **business thinking**.

I believe organisations don't invest in dashboards, SQL queries, or programming languages.

They invest in **better decisions**.

Every organisation asks questions.

- Why are sales declining?
- Which customers create the most value?
- Which marketing campaigns deserve more investment?
- Where are we losing customers?
- How can reporting become more reliable?
- Which operational improvements will create the greatest impact?

Those questions drive every project in this portfolio.

Each case study demonstrates how Business Intelligence and Analytics can transform raw data into actionable insights that support confident, evidence-based decision-making.

---

# My Philosophy

Technology is never the starting point.

**Business is.**

Every project follows the same analytical framework.

```text
Understand the Business
          │
          ▼
Ask the Right Question
          │
          ▼
Collect & Prepare the Data
          │
          ▼
Explore the Evidence
          │
          ▼
Generate Insights
          │
          ▼
Recommend Actions
          │
          ▼
Create Business Value
```

Everything else—SQL, Power BI, Python, dashboards, and visualisations—is simply the toolbox.

The business problem always comes first.
